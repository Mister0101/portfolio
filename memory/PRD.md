# PRD — Ilya Daniliuk Personal Portfolio

## Original Problem Statement (summary)
Premium, modern personal portfolio website for Ilya Daniliuk targeting recruiters, hiring managers and technology companies. Positioning: NOT a junior developer — combines business development/commercial experience, technology & cloud knowledge, customer/stakeholder skills, operations experience, hands-on software/cloud/AI projects and certifications. Target roles: Business Development Manager (technology), IT/Cloud/Cybersecurity Sales, Technology Account Manager, SaaS BD, Technology Partnerships, business-facing cloud/AI roles. All content sourced ONLY from provided materials (CV docx + LinkedIn screenshots); missing info shown as identifiable placeholders. Design: sophisticated, premium, clean typography, generous whitespace, subtle animations, minimal gradients, no stock imagery, responsive.

## Architecture
- React 19 + Tailwind CSS + shadcn/ui + framer-motion + lucide-react (no backend, no DB, no auth — per requirements)
- Central data config: `/app/frontend/src/constants/portfolioData.js` (profile, about, expertise, projects, certifications, experience, nav) — edit this single file to update content
- Components: `/app/frontend/src/components/portfolio/` — Navbar, Hero, About, Expertise, Projects (+case-study Dialog), Certifications, Experience, Contact (mailto form + sonner toast), Footer, shared Section
- Design system: obsidian dark (#080C14), cobalt accent (#3B82F6), Plus Jakarta Sans headings / Inter body / JetBrains Mono labels (`/app/design_guidelines.json`)
- Downloadable CV: `/app/frontend/public/Ilya-Daniliuk-CV.pdf` generated by `/app/scripts/make_cv_pdf.py` (fpdf2). Phone number intentionally EXCLUDED from web CV for privacy
- SEO + Open Graph metadata in `/app/frontend/public/index.html`

## User Personas
- Recruiter / hiring manager scanning in ~15 seconds
- Technology company BD/sales team lead evaluating commercial + technical fit

## Core Requirements (static)
Sticky nav (Home/About/Projects/Certifications/Experience/Contact) with smooth scroll; Hero with headline + value prop + View Projects/Download CV CTAs + LinkedIn/GitHub; About connecting commercial & tech experience; 3-group expertise (no skill bars); project cards with case-study modal, repo/demo links; certification cards grouped by issuer with credential IDs + verify links; concise experience timeline; contact section (LinkedIn/GitHub/email + simple form, no accounts); minimal footer; responsive; accessible; OG metadata.
